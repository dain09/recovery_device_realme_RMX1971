# OrangeFox Recovery Project - Realme 5 Pro (RMX1971)

OrangeFox Recovery tree for **Realme 5 Pro (RMX1971)**.

## Features

Works:

 - Decryption
 - OTG
 - Vibration / Haptics
 - **exFAT Support (Mainline Driver)**
 - Flashlight
 - Everything else


## Note about ozip decrypt
* This is necessary for downgrades back to stock android-9.0 (ColorOS).
* Early versions of android-10.0(Realme UI v1) have decryptor built into the updater binary so this patch isnt necessary.
* Later versions of android-10.0(Realme UI v1) are not ozip encrypted at all.
